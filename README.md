# Course Description

I am Mohamed Salman Afan, and this repository contains my learning notes, exercises, and practical work for the Web Application Development - PHP & MySQL course. This course helps me understand how dynamic, database-driven web applications are built using PHP and MySQL.

Through this course, I am learning server-side programming, form handling, database design, SQL queries, AJAX, REST API development, authentication, security, MVC architecture, and Laravel fundamentals. # My Course Objectives

By the end of this course, I aim to be able to:

- Understand the basics of web application development and how PHP/MySQL applications work.
- Build dynamic and interactive web pages using PHP.
- Work with PHP variables, data types, operators, control structures, arrays, functions, and reusable files.
- Create and process HTML forms with validation and error handling.
- Develop interactive applications using jQuery, AJAX, and JSON.
- Understand relational database concepts and MySQL database design.
- Write SQL queries such as:
  - SELECT
  - INSERT
  - UPDATE
  - DELETE
  - CREATE
  - JOIN operations
- Connect PHP applications safely with MySQL databases.
- Develop CRUD-based applications.
- Build REST APIs using PHP and MySQL.
- Implement authentication, authorization, cookies, and sessions.
- Understand MVC architecture and Laravel project structure.
- Design and develop complete database-driven web applications.
